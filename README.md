# Лабораторная работа №1 — анализ и прогнозирование временных рядов

Готовый Jupyter Notebook содержит EDA, классическую/STL-декомпозицию, FFT,
вейвлет-анализ db4, перебор ARIMA/SARIMAX, MSE/R², AIC/BIC и диагностику остатков.

## Запуск
```bash
pip install -r requirements.txt
jupyter notebook lab1_retail_sales.ipynb
```

Последние 12 месяцев используются как тестовая выборка.
Сезонный период — 12 месяцев.
